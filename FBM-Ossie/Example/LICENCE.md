# Example Licensing and Provenance

The example directory contains models from more than one source.

## Apache Ossie examples

The following YAML files contain Apache Software Foundation licence headers and remain licensed under the Apache License, Version 2.0:

- `flights.yaml`
- `tpcds_semantic_model.yaml`

Their retained file headers are authoritative. Any modifications made in this repository should be identified as modifications.

## Generated or FactEngineCommunity examples

- `flights.fbm` is a converted FBM representation associated with the Apache Ossie Flights example.
- `CinemaBookings.fbm` is an FBM example used to exercise conversion, including objectified Fact Types.
- `CinemaBookings.yaml` is the corresponding generated or converted Ossie representation.

The exact authorship and generation history of these three files must be confirmed before the first public release.

## Release requirement

Before publication, record for every example its source, whether it is original, copied, modified, or generated, the licence permitting distribution, and any required attribution.
